## Подтверждено кодом

- `db/migrations/000024_catalog_publications.js`: отдельное право, INSERT runtime на новые версии, SELECT/INSERT publication evidence с RLS; guard защищает неизменяемость и последовательный same-identity snapshot. Down запрещён ради истории, rollback — выключить publication flag.
- `packages/domain/src/admin/publish.ts`: active actor/session, два exact-scope права, flag, idempotency hash, advisory identity и quota row barrier; reread срока после ожидания и перед commit. Server timestamp с микросекундами, новая версия/основание/response атомарны. Ни balance, quota, redemption, outbox не переписываются.
- `apps/app/src/shared/server/catalog-publication.ts`: строгий POST, Origin/CSRF, ограниченное тело, общий actor limiter, no-store ответы. GET catalog `canPublish` — подсказка; POST повторно проверяет authority. `packages/domain/src/admin/audit.ts` включает publication snapshot в scoped центральный журнал.
- `apps/app/src/features/catalog-admin/catalog-publish.tsx`: обязательная причина, отдельное подтверждение, замороженный body/key при неизвестном результате/429, отказ новой попытки при конфликте, dirty/Back/access cleanup. У каждого sibling собственный React key. Textarea имеют явные подписи, поля 16 px, native controls 44 px. Existing world/tokens/dependencies сохранены.
