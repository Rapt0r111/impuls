# F07 и компактная навигация: локальная проверка

Дата: 02.10.2026, Europe/Moscow. Основание: IMPLEMENTATION_PLAN.md §§ 4, 6, 7, 10–12, строка F07; последующее замечание пользователя о неровных и нелаконичных кнопках на 320 px. Контракты: ADR-0007, `docs/implementation/2026-10-02-f07-audit-slice.md` и `2026-10-02-workspace-navigation-refinement.md`. Это свидетельства локального среза, не приёмка F07/R1.

## Подтверждено кодом

- `db/migrations/000016_scoped_audit_reader.js`: независимое действие `admin.audit`, индекс времени/UUID, отсутствие автоматической выдачи полномочий; отказ down при сохранённых назначениях этого права. Существующие RLS и запрет UPDATE/DELETE аудита для runtime сохранены.
- `packages/domain/src/admin/audit.ts`: текущая активность/сессия и точное право проверяются в одном SQL-снимке с доступными событиями. Нет наследования области и полномочий от проверки/постановки задач. Только синтетические правила. Review и correction разрешаются через submission/review до задачи; прямой `task_id` у этих событий не предполагается.
- Курсор привязан к субъекту, области и фильтру, сервер проверяет доступность anchor; seek сохраняет микросекунды `(created_at,id)`. Это живое чтение страниц, не замороженный снимок всего журнала. Список не выдаёт сырой diff, Telegram ID, session hash или неизвестные значения. Текущие имена/названия отличены от сохранённых оснований и scalar-полей.
- `packages/contracts/src/audit.ts` и `apps/app/src/app/api/v1/admin/audit/route.ts`: строгие query/response schemas, отказ повторным/неизвестным параметрам, no-store, выключенный по умолчанию `SYNTHETIC_AUDIT_ENABLED`. Раздельные 400/401/403/404/503; клиентские кнопки не дают серверных прав.
- `apps/app/src/features/audit/audit-log.tsx` и `.css`: scope/action, ручное обновление, пагинация и inline disclosure. При 503 остаются подтверждённые строки и прежнее время; при 401/403/404 защищённые строки скрываются. Смена фильтра сбрасывает страницы, обновление начинает чтение заново.
- `features/tasks/task-list.tsx`, `features/auth/access-screen.tsx`, `app/globals.css`: четыре равных личных пункта и отдельная строка доступных рабочих разделов; короткие подписи, один mint selected state, 44 px цели, gold keyboard focus. Полномочия в native details, guarded logout в шапке. Несданный отчёт и native Back защищены прежним guard. Reduced motion отключает переходы навигации. Зависимости, токены и R0 sidecar не менялись этим срезом.

### Встреченные сбои

- Первый pg_ctl под restricted token получил OS error 87. Разрешённый loopback-запуск успешен; automatic approval review действие не отклоняла.
- Первая фикстура пыталась отправить отчёт сразу после возврата. Исправлена на фактический доменный переход повторного начала работы; конфликт больше не возникает.
- Первоначальная выборка предполагала прямой task_id у review/correction-аудита. Исправлена по реальным внешним ключам, все семь действий проверены доменными записями.
- Initial TypeScript exactOptionalPropertyTypes/union и JSX-размещение wrapper дали ошибки. Исправлены; последующие сборки прошли.
- Real HTTP browser не находил фильтр действия по имени; явные aria-labelledby исправили связь label/select. Focus-проверка переведена на настоящий keyboard Tab/Enter.
- Первые быстрые captures показывали промежуточный цвет перехода. Добавлены reduced-motion nav и стабильный capture с `animations: disabled`, hover убран; финальные восемь PNG перечитаны.
- Дополнительный старый access-smoke ожидал всегда раскрытые полномочия и не мокировал новые task/review reads. Эти реальные неподписанные запросы скрывали сессию, которую сам тест предварительно мокировал успешной. Фикстура теперь раскрывает native details и возвращает отдельные синтетические пустые рабочие списки; повтор всех семи сценариев прошёл. Серверные проверки отзыва не менялись.

Ожидаемый negative API 503 лимитера и существующий Node MODULE_TYPELESS_PACKAGE_JSON присутствовали в полном прогоне; exit 0. Не выдаются за падение или за непроверенную команду.

## Непроверенное и решения владельца

Миграция/код не развёрнуты в Supabase/Vercel; удалённый PostgreSQL 17.6 CI не запускался. Chromium и SDK mocks не являются проверкой Telegram WebView, Android/iOS, screen reader или реального увеличения системного шрифта. Не проверены восстановление production, эксплуатационная нагрузка, доставленные уведомления и полный административный контур. P-01…P-06 открыты; real-data доступ и реальные поощрения не согласованы. F07/R1 не объявлены завершёнными.

Использованы установленная документация Next.js Route Handlers, React guidance, Supabase docs MCP ([RLS](https://supabase.com/docs/guides/database/postgres/row-level-security), [roles](https://supabase.com/docs/guides/database/postgres/roles)) и [PostgreSQL statement snapshots](https://www.postgresql.org/docs/17/transaction-iso.html). Supabase changelog не удалось прочитать через web из-за text/markdown; его актуальность не утверждается. Новых или обновлённых зависимостей нет.
