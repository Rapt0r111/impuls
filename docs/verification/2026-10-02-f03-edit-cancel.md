## Сбои промежуточных прогонов

Первые новые fixtures не задали active=true и создали сессии до выдачи прав (триггер отзывает их); это исправлено в тестовом setup. Старые ACL-тесты ожидали отсутствие UPDATE условий: обновлены на новый контракт вместе с отрицательными SQL-проверками trigger, а не удалены. Реальный browser-тест сначала искал неверное имя навигационной кнопки; исправлен селектор и сделано уникальное название fixture. Браузерный replay выявил нестабильные label-имена textarea; исправлен production UI через aria-labelledby. Прежний management-тест иногда проверял closing confirmation до завершения React effect; теперь ждёт фактического снятия guard. Каждый перечисленный сбой был исправлен до финального успешного прогона.

Намеренный тест отказа счётчика выводит обезличенный api_error 503 и проходит. Сохраняется предупреждение Node MODULE_TYPELESS_PACKAGE_JSON из existing session-cookie.ts. Chromium создал debug.log с SSL-ошибками фоновым запросам; файл перенесён в игнорируемую `.local/f03-edit-browser-debug.log`, тестируемые локальные операции прошли. Это не проверка внешнего TLS-контура.
