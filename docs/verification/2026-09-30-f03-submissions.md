## Подтверждено исходниками

- `db/migrations/000007_task_submissions.js`: неизменяемые отчёты с уникальным номером попытки, UUID-ключи идемпотентности, SHA-256 запроса и сохранённый ответ; RLS, ограниченные гранты и UPDATE-политика задач. Исправлено отсутствие UPDATE-политики в начатом коде: одного column grant недостаточно для записи под RLS.
- `packages/domain/src/tasks/write.ts`: одна транзакция на одном client, блокировки допуска/сессии/задачи, повторная проверка действующей сессии внутри транзакции, назначение, ожидаемая версия и допустимый переход. Повтор проверяет доступ перед выдачей сохранённого ответа; изменённое тело/цель возвращает конфликт. Отчёт и изменение версии либо сохраняются вместе с ответом, либо откатываются.
- `packages/contracts/src/tasks.ts`: строгие запросы, положительная версия, UUID-ключ, текст 1–4000 символов после trim. `PATCH /tasks/:id` этого среза принимает только `action: start`, не произвольное редактирование. `apps/app/src/shared/server/task-mutation.ts`: Origin, CSRF, сессия, JSON-контракт, лимит тела 32 768 байт (проверен отчёт из 4000 трёхбайтовых символов), единые ошибки и `private, no-store`.
- `apps/app/src/features/tasks/task-report.tsx`: начало работы, форма, последний серверный отчёт, подтверждение без начисления, сохранение текста при временном сбое и 409, повтор прежнего ключа/тела при неизвестном результате. Автоматической повторной мутации нет. Несданный текст хранится только в памяти открытого экрана.
- `apps/app/src/features/auth/session-context.tsx`, `access-screen.tsx`: CSRF доступен авторизованным клиентским компонентам; предупреждение об уходе и выходе, browser `beforeunload`, закрытие рабочих данных после 401/403. Поддерживаемый клиент Telegram получает closing confirmation через [официальные методы Bot API 6.2+](https://core.telegram.org/bots/webapps#initializing-mini-apps); физическая работа на устройствах не проверена.
- `scripts/verify-task-slice.mjs`, `package.json`, `.github/workflows/check.yml`: воспроизводимый прогон после сборки — локальный production Next.js, PostgreSQL/HTTP/браузерные проверки, завершение сервера. Его подключения используют `options=-c role=impuls_app`; административное соединение применяется только тестовыми фикстурами. PostgreSQL 17.6 остаётся целевой БД CI.
