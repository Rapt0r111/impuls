# Визуальное обновление мобильного интерфейса (09.10.2026)

Основание: запрос пользователя «практично, читаемо, удобно для телефона», затем «современно и живо, можно менять цвета»; макет из шести экранов одобрен как направление. Описание системы — раздел «Обновление визуального слоя Mini App» в `DESIGN.md`.

## Что изменено (подтверждено файлами)

- `apps/app/src/shared/ui/tokens.css`: светлее `--color-gold` и `--color-muted`; новые тона, граница, стекло и кривые движения. `--color-bg` не менялся.
- `apps/app/src/app/globals.css`: атмосферный фон, анимации появления, плавающая нижняя капсула, карточки задач и деталей, градиентные кнопки, поле отчёта, чипы; подписи ≥14 px (нижняя панель — 12/11/10 px по ширине); `prefers-reduced-motion`.
- `apps/app/src/features/home/home.{tsx,css}`: кольцо уровня (декоративное), плитки баллов, главная карточка ближайшей задачи.
- `apps/app/src/features/ranking/leaderboard.css`, `rewards/rewards.css`, остальные `features/*/*.css`: пьедестал, карточки, размеры шрифта.
- `apps/app/src/features/tasks/task-list.tsx`: значок вкладки обёрнут в `.workspace-tab-pill` (метки и `aria-label` без изменений).
- `tests/browser/telegram-bridge.mjs`: ожидаемый нижний отступ оболочки 126 → 146 px (капсула стала выше и вынесена от края на 10 px).

## Проверено командами

- `npx prettier --write` на изменённых файлах; `bun run typecheck` и `bun run lint` — без ошибок; `bun run test:unit` — 164 теста прошли (остальные требуют БД).
- `bun run test:reflow` — 150 сценариев, 0 сбоев (320/360/390/1280 px, крупный текст).
- Браузерные сценарии на production-сборке без БД: home 5, ranking 14, rewards 29, profile 27, tasks-smoke, telegram-bridge 14, reward-decisions 30, reward-fulfillment 26, task-* и audit/каталог/квоты — все прошли.
- `bun run db:local up` (после остановки зависшего кластера) и `bun run test:task-slice` с `TEST_DATABASE_URL`/`PG_BIN` — код 0: Vitest 52 файла, 434 теста прошли, 4 пропущены, затем все браузерные сценарии.
- Снимки главной и задач на реальном интерфейсе при 390 px просмотрены вручную; рейтинг и поощрения — по снимкам тестов.

## Не проверено

- Физический Telegram Android/iOS и производительность `backdrop-filter`, фиксированных градиентов и анимаций на слабых устройствах.
- Контраст новых пар цветов инструментом; чтение скринридером; `access-smoke.mjs` ожидает `localhost:3000` и в этом прогоне не запускался.
- Внешний выпуск (Vercel Production) не выполнялся; решения P-01…P-06 и приёмка R1 остаются открытыми.

## Дополнение: сверка с утверждённым макетом кадр в кадр

Причина: владелец сообщил, что приложение не соответствует макету. Макеты (`tmp/fid/mock-*.html`, собраны из файлов артефакта) и реальное приложение с теми же данными отрисованы в Chromium 390×844 и сопоставлены рядом (Главная, Задачи, Рейтинг, Поощрения).

Найдено и исправлено:

- `body` с непрозрачным фоном закрывал свечение и точечную сетку (негативный z-index) — фон теперь задаёт только `html`.
- Шапка: на «Главной» приветствие и имя крупно, «Полномочия» — кнопка-значок (подпись остаётся текстом); на остальных экранах компактная строка (`html[data-view]` ставит `TaskWorkspace`).
- «Главная» пересобрана по макету: «Ближайший срок» с кнопкой «Открыть задачу», кольцо уровня и плитка баллов с резервом, «Ещё в работе» со ссылкой «Все задачи»; пустое состояние — тот же стиль. Удалены кнопки «Журнал начислений» и нижняя ссылка «Все задачи» (журнал доступен через «Баланс»).
- Задачи: карточка с плиткой состояния, чипом статуса, сроком, чипами «+XP/+баллы» и приоритетом; фильтр статуса — лента чипов вместо `<select>`; кнопки обновления в заголовках — значки.
- Рейтинг: компактные фильтры, инициалы на пьедестале по словам имени, таблица без шапки (шапка остаётся для скринридеров), строка «вы» плиткой. Поощрения: золотая карточка баланса, жирные названия.

Отличия от макета, оставленные сознательно: экрана «Ещё» и отдельного экрана «Задача и отчёт» нет (раскрытие внутри списка); в таблице рейтинга первые три места повторяются под пьедесталом (пьедестал скрыт от скринридеров, таблица — единственный доступный источник); у Главной нет строки «осталось N ч»; заголовок «Назначенные задачи» вместо «Задачи» (на него опираются тесты); есть строка «XP за месяц» и подпись «Данные на…».

Проверено: `bun run test:reflow` — 150 сценариев, 0 сбоев; `bun run test:task-slice` с локальной PostgreSQL — 52 файла, 434 теста прошли, 4 пропущены, все браузерные сценарии, код 0; lint, typecheck, prettier — без замечаний. Не проверено: реальный Telegram.

- Тесты: браузерные и интеграционные сценарии открывают раздел через «Ещё»; `workspace-reflow.mjs` ждёт `.workspace-nav-personal` (контейнер `<nav>` имеет нулевую высоту — капсула фиксирована) и проверяет клавиатурой вкладку «Ещё».
- Проверено: `bun run test:reflow` — 150 сценариев, 0 сбоев; `bun run test:task-slice` (локальная PostgreSQL, `PG_BIN` задан) — 54 файла, 441 тест прошёл, 4 пропущены, код 0; `typecheck`, `eslint` — без замечаний. - Не проверено: Telegram Android/iOS, производительность анимаций на слабых устройствах.
- Отличия от концепта: см. запись в `DESIGN.md` за 10 октября 2026.
