# F08/F07: проверка журнала попыток симуляции

Дата: 05.10.2026. Основание: IMPLEMENTATION_PLAN.md §§ 3–4, 8, 10–12, F08/F07; [контракт до реализации](../implementation/2026-10-05-f08-attempt-journal-slice.md), [ADR-0015](../adr/0015-synthetic-notification-attempt-journal.md). Это локальный синтетический срез, не полная приёмка R1.

## Подтверждено кодом

- `db/migrations/000023_notification_attempt_journal.js` добавляет private append-only `notification_simulation_events`. SECURITY DEFINER AFTER UPDATE trigger имеет фиксированный `search_path=pg_catalog`, явные имена таблиц, отозванный PUBLIC EXECUTE; app/worker не получают INSERT/UPDATE/DELETE/TRUNCATE. RLS и SELECT app распространяются только на минимальные поля. Нет Data API grants или выдачи прав. UPDATE/DELETE запрещены также guard trigger. Журнал и receipt сохраняются либо откатываются вместе.
- Записываются started, retry/simulated/failed/suppressed, обнаруженное lease_expired; восстановление пишет конец старого захвата и начало нового, пятая потеря — lease_expired/failed. Старые ready/processing/terminal receipts не меняются и не получают backfill. Для начатой до миграции попытки может сохраниться outcome без выдуманного started. Исходный outbox, суммы, доступ получателя, алгоритм retry и lease сохраняются.
- `packages/contracts/src/notification-attempts.ts` и `packages/domain/src/notifications/attempts.ts`: strict wire projection, номер 1–5, allowlisted phase/reason, exact `admin.notifications`, active session/subject и доступный native timestamp/id anchor в одном statement snapshot. Cursor связан с actor/scope/purpose/journalId. История synthetic источника сохраняется при выходе outbox из pending. В ответе есть только служебные journal/event UUID, тип, номер, фаза, время записи и фиксированная причина; нет recipient/business source IDs, lease, текстов и сырых ошибок.
- `apps/app/src/app/api/v1/admin/notifications/attempts/route.ts`: Node GET, private/no-store, duplicate/unknown queries запрещены, прежний flag false по умолчанию, 400/401/403/404/503; POST 405. Новый API/UI требуют предварительной 000023; выпуск совместный.
- `apps/app/src/features/notifications/notification-attempts.tsx`: выбранное пользователем закрытое lazy раскрытие, refresh первой страницы, next, самостоятельная дата МСК, loading/empty/error/retained503, secondary event identity и Telegram Back. Время записи/обнаружения lease не выдаётся за доставку. `notification-cache.ts` используется также сводкой и списком событий: отказ любого чтения отменяет параллельные queries и очищает все три protected caches; rejecting query не отменяет сам себя. Scope key, response scope check и AbortSignal защищают от late response.
- `apps/worker/src/index.ts`: обнаруженный raw stack trace исправлен постоянным neutral error listener нового pg client; pg-pool снимает idle listener при checkout, поэтому одного `pool.on('error')` было недостаточно. Ошибка сокета останавливает loop, сохраняет lease и выводит только WORKER_UNAVAILABLE. Доменные операции и внешний supervisor этим не меняются.
