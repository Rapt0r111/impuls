# «Импульс»: оценка реализации и сайт-отчёт

Состояние локального репозитория на 5 октября 2026 года. Это аналитическая оценка, не приёмка R1 и не прогноз сроков. Требование пользователя: показать процент реализации, остаток до релиза и сделать небольшой сайт с иллюстрациями, схемами и графиками. Основание объёма — IMPLEMENTATION_PLAN.md §§10–12, PRODUCT.md и фактический код.

## Созданный артефакт

- `outputs/system-progress-site/`: сайт на общем проверенном React/report runtime Data Analytics, без установки зависимостей или изменения стека сервиса.
- Authored entry: `src/content/report/ProgressReport.jsx`; CSS `progress.css`; тема `src/theme.css`; reviewed evidence `src/data.json`.
- Два графика: горизонтальное покрытие функций и состав критериев. Переключатель R1/R2/весь объём пересчитывает числитель, знаменатель, строгую оценку, графики и рубрику. Источники блоков содержат соответствующие scoped rows.
- Схема UI → API → domain → PostgreSQL, предметная транзакция и отдельный симуляционный worker. Bot API явно показан как отсутствующий.
- Четыре существующих PNG из браузерных проверок локального UI; исходные изображения сохранены, превью кадрирует только CSS, диалог показывает полный снимок.
- P-01…P-06 и пять групп инженерных условий выделены отдельно. Процент готовности к пилоту не выдумывался.
- Использованы `data-analytics:build-report`, `data-analytics:visualize-data`, `frontend-references`, установленный Data runtime и браузерный инструмент. Визуальный референс — существующий DESIGN.md: navy, mint, gold. Внешние дизайн-источники и новые библиотеки не потребовались.

## Неизвестное и остаток

Нужны админ операции допуска/прав/правил/каталога/квот, бонусы, настоящее Telegram-уведомление и hosting worker, автоматическое истечение резервов и утверждённые правила отмены. Затем адаптация синтетического режима к разрешённым реальным правилам и данным.

P-01…P-06 не подтверждены. Не проверены в этой работе: текущее удалённое развёртывание, PostgreSQL 17.6 CI, фактическая доставка Telegram, ручные Android/iOS, security scan/актуальные зависимости, целевой TLS/CA, нагрузка и restore. Требуется согласованный выпуск app/API/worker и миграций. R2 не блокирует первый пилот; F09–F12 остаются для полного целевого объёма. Ни R1, ни сервис целиком не объявляются готовыми.

## Воспроизведение отчёта

Из корня репозитория:

```powershell
node scripts/build-system-progress-snapshot.mjs
node scripts/update-system-report-data.mjs --complete
node scripts/verify-system-report.mjs
# Установленный Data Analytics plugin, без установки пакетов:
node "$env:USERPROFILE/.codex/plugins/cache/openai-curated-remote/data-analytics/1.0.11/scripts/data-app.mjs" build --project-dir outputs/system-progress-site --separate-data
python -m http.server 4178 --bind 127.0.0.1 --directory outputs/system-progress-site/dist
```

При отсутствии python в PATH использовать bundled Python из `load_workspace_dependencies`. Просмотр: `http://127.0.0.1:4178/`. Сервер обслуживает весь dist, включая content-addressed JSON. Сайт не публиковался во внешнем контуре.
