# F02/F07: браузер → реальная БД для «Доступ» и «Журнал»

Дата: 08.10.2026. План: [docs/superpowers/plans/2026-10-08-browser-to-database-access-audit.md](../superpowers/plans/2026-10-08-browser-to-database-access-audit.md). Основание: ADR-0023, IMPLEMENTATION_PLAN.md §§ 11–13. Синтетика; F02/F07/R1 и P-01…P-06 не приняты. Продуктовый код не менялся.

## Среда

Windows, Node 24.21.0, Bun 1.4.2, PostgreSQL 18.6 (синтетический кластер `.local/creation-pg`, запущен на `127.0.0.1:55444`, база `impuls_cancellation`). Порт 55434 в этот раз занят другим сервером PostgreSQL с паролем, порт 55435 недоступен (Permission denied), поэтому использован 55444. Целевой Linux/PostgreSQL 17.6 не проверялся.

## Не проверено

Сценарий выполняет только основной поток. Отрицательные ветки (потеря доступа администратором при открытой странице, повтор после успеха, скрытие журнала без `admin.audit`) в реальной БД через браузер не проверялись; их покрывают интеграционные тесты и mock-сценарии. Скриншоты `test-results/task-slice/<pid>/access-real/` не просматривались. Telegram WebView, устройства, Linux 17.6 CI, P-01…P-06 и приёмка R1 открыты.
