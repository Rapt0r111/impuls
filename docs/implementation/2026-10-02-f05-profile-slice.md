# F05: локальный профиль, уровни и первое достижение

Требование: IMPLEMENTATION_PLAN.md §§ 5, 7, 10–12, строка F05. Инженерный контракт: ADR-0006.

Подтверждено кодом: миграция 000015, атомарная косметическая выдача с приёмкой, чистый расчёт порогов, owner-only API и вкладка «Мой профиль» в существующем workspace. Сессия/допуск/баланс/правила/источник читаются в одном repeatable-read snapshot; истечение сессии повторно проверяется перед возвратом. Нет начислений от чтения профиля.

UI сохраняет guard несданного отчёта и native Back. Использует существующие flat rows, tokens, Manrope и 44 px действия. Показывает текущий XP, уровень/порог/остаток с подписанным native progress и основание «Первого результата». Состояния: loading, нет приёмок, не настроенные/ошибочные правила, последний уровень, исправленный источник, flag disabled, ошибка/сеть с timestamp последнего подтверждения, скрытие данных при 401/403/404. Обновление ручное, Query отменяет запрос через AbortSignal; автоматический retry выключен.

Уровни и достижение синтетические. Реальные пороги, последствия корректировок, видимость и пилот требуют P-04/P-05/P-01…P-06. Сезонные снимки, администрирование конфигурации, R2 и delivery worker не входят в этот срез. Новые зависимости отсутствуют.

Результаты команд и непроверенные части записываются в `docs/verification/2026-10-02-f05-profile.md` после выполнения проверок.
