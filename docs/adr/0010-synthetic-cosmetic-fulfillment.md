# ADR-0010: выдача синтетической косметики

Дата: 03.10.2026. Статус: локальная инженерная граница; P-03/P-04 не утверждены.

Продолжаем ADR-0009 отдельным `reward.fulfill`: approved → fulfilled выдаёт immutable entitlement, уникальный по получателю/предмету/точной области. Автор выдачи не получатель; он может быть автором согласования при наличии отдельного права. Сохранённое согласование и условия не переписываются. Баллы и квота расходуются при approve, выдача не списывает их повторно.

В synthetic-контуре косметика приобретается один раз в своей области, включая последующие версии цены/квоты. Уникальный индекс заявок включает fulfilled; каталог явно показывает владение. Реальная политика предметов, повторной покупки, передачи/отзыва и служебных наград требует отдельного решения.

Существующие approved не получают entitlement при upgrade. Только явная транзакция выдачи создаёт evidence, audit/outbox и idempotent response; отложенный constraint trigger запрещает fulfilled без соответствующей записи. Runtime не имеет UPDATE/DELETE entitlements. Схема остаётся закрытой от Data API.

Откат приложения закрывает SYNTHETIC_REWARDS_ENABLED; миграция forward-only сохраняет историю. Перед внешним выпуском нужен совместимый reader новых статусов. Проверки и ограничения фиксируются в отчёте среза; PostgreSQL 17 CI и Telegram устройства не заменяются локальным PostgreSQL/browser.
