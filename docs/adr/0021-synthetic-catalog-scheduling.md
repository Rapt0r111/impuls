# ADR-0021: отдельная отложенная публикация условий

Дата: 05.10.2026. Статус: принято как технический контракт синтетического режима, не решение P-03/P-04.

## Причина и решение

F07 умеет немедленно публиковать условия; схема и readers уже выбирают версии по effective_from. Добавляем append одной будущей версии через отдельные право, endpoint, default-false flag и idempotency operation. Общая серверная транзакция публикации переиспользует identity/quota barrier, immutable evidence и повторную проверку authority. Дата сравнивается с clock_timestamp после ожиданий и при INSERT.

## Последствия и миграция

000029 расширяет allowlist действий, не выдаёт полномочий и не меняет экономику. Таблицы, transport/runtime и зависимости сохраняются. Общий catalog_publications/audit показывает createdAt отдельно от effectiveFrom; activation не создаёт повторного события или начисления. Сначала миграция, затем совместимый API/UI; rollback выключает scheduling flag, сохраняя историю. Записанная будущая версия продолжает действовать по сохранённой дате при выключении write flag; остановка writes не отменяет условия. Для отмены нужен отдельный контракт, задним числом версии не правятся.

## Измерение и проверки

Сравниваются независимые ожидаемые current/scheduled versions, price/quota/balance/redemption snapshots, число publications и неизменный replay. Проверяются точные права, ошибки HTTP, время после lock wait, гонки, UI и restore. Нагрузка и физический Telegram не проверены этим решением; production performance claims не делаются.
