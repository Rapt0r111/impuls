# ADR-0007: независимый просмотр синтетического аудита

Дата: 02.10.2026. Статус: локальное техническое решение для режима ожидания.

F07 требует журнала административных решений, однако существующие `admin.access` и `task.view` обозначают другие полномочия. Используем отдельное точное `admin.audit`, выключенный по умолчанию синтетический reader и существующие неизменяемые `audit_events`. Область выводится из реляционного объекта события, а не из клиентского поля или JSON diff. Возвращается разрешённая типизированная проекция сохранённых значений, без произвольного JSON и реконструкции отсутствующей истории.

Next.js Route Handler остаётся тонким HTTP-адаптером, запрос и авторизация — в доменном модуле `admin/audit`; PostgreSQL, runtime и transport не меняются. Миграция 000016 меняет только enum действия и добавляет индекс, не выдаёт права. Down блокируется существующими назначениями `admin.audit`; оператор сначала отзывает/архивирует их по отдельной процедуре, запись автоматически не уничтожается.

Последствия: аудит не даёт права на мутации и не показывает несинтетические правила. Фильтр/субъект/область привязаны к anchor курсора; новые строки требуют обновления для появления вверху. Проверяем отдельные права, отзыв, anchor, точные микросекунды, неизменяемость, HTTP и мобильные состояния. Реальная видимость/допуск остаются P-01/P-02; полнота административного управления, эксплуатация и пилот остаются открытыми.
