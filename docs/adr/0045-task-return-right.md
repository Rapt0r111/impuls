# ADR-0045: право `task.return` — вернуть отчёт на доработку без права принять

Статус: принято, 26.10.2026. Миграция 000054 к Production не применена: только по слову владельца.

## Контекст

Решение владельца: итоговое решение по баллам и XP на всех задачах принимает только командир. Проверяющие должны видеть отчёты и возвращать их на доработку, если нашли недочёт. До этого ADR `task.review` давало оба действия: принять отчёт (с начислением по фонду задачи, корректировкой базы и надбавкой) и вернуть его. Право было неделимым, поэтому проверяющий без `task.review` не мог вернуть работу, а с ним получал решение по баллам.

## Решение

- Новое право `task.return` («Возврат на доработку»): очередь проверки и возврат отчёта в своей области. Принять отчёт оно не позволяет.
- `task.review` по-прежнему даёт всё: очередь, возврат и приёмку. Командир ничего не теряет.
- `packages/domain/src/tasks/reviews.ts`: очередь и возврат проверяют `task.review` или `task.return`, приёмка только `task.review`. Приёмка без права отвечает `not_found`, как и остальные отказы по правам. Проверка повторяется после блокировок, как раньше.
- Очередь отдаёт `acceptance.enabled = false` и пустые варианты тому, у кого нет `task.review`; интерфейс при этом показывает только «Вернуть на доработку».
- Миграция 000054 добавляет `task.return` в CHECK `role_bindings_action_check`. Откат удаляет выдачи `task.return` и возвращает прежний CHECK.
- Самостоятельные задачи (ADR-0040) не меняются: у проверяющего `task.verify` остаются «одобрить с оценкой» и «отклонить».

## Последствия

- Порядок выкатки: миграция 000054 на Production, затем приложение, затем выдача `task.return` проверяющим. Старый код не знает права и не мешает ему лежать в базе.
- Владельцу и командиру выдавать `task.return` не нужно: `task.review` его включает. `scripts/bootstrap-owner.mjs` для новых баз выдаёт и его.
- Возврат записывается так же, как возврат держателем `task.review`: запись проверки, аудит, уведомление исполнителю.

## Проверки

- `tests/integration/task-return-right.test.ts`: очередь без приёмки, возврат с одним `task.return`, отказ в приёмке, отказ участнику без прав.
- Существующие проверки очереди, возврата, приёмки и самостоятельных задач проходят на PostgreSQL 16 с миграцией 000054; откат и повторное применение 000054 проверены локально.
