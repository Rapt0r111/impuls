# ADR-0037: свободные задачи, которые участник берёт сам

- Статус: принято локально
- Дата: 12.10.2026
- Авторы и утверждающие: исполнитель по просьбе владельца 12.10.2026 («Она нужна» в ответ на вопрос, нужна ли задача без исполнителя).

## Контекст

Черновик без исполнителя уже существует (§ 11 F03), но участники его не видят и не могут взять. Владельцу нужна задача, которую любой участник области берёт сам.

## Решение

- Миграция 000043: `tasks.open_for_claim boolean NOT NULL DEFAULT false` и частичный индекс по черновикам со свободным флагом. Флаг ставится только при создании; роль приложения не имеет права его менять.
- Свободная задача — черновик с флагом. Её видят и могут взять активные участники области задачи (`task_scope_members`, действующее окно). Посторонний получает 404.
- «Взять»: `POST /api/v1/tasks/{id}/claim` с `expectedVersion` и ключом идемпотентности (`task.claim`). Операция блокирует строку (`FOR UPDATE`), вставляет `task_assignments` (UNIQUE по задаче), ставит статус «Назначена», версию +1 и событие `assigned`, где автор равен исполнителю (в истории: «Исполнитель взял задачу сам»). Просроченную, уже взятую или изменённую задачу взять нельзя (409). Из восьми одновременных попыток побеждает одна.
- Список: `GET /api/v1/tasks/open` (до 50 записей).
- Включается тем же `TASK_MANAGEMENT_ENABLED`; отдельного флага нет.
- Запись в журнал действий не добавляется (как для «Начать» и «Отправить»).
- **Предел взятых задач** (владелец 12.10.2026: «пока не нужен, либо пусть командир выставляет, либо без лимита»). Настройка `openTaskLimit` (1–50 или «без предела», по умолчанию без предела) хранится в определении настроек начислений и меняется на экране «Настройки начислений», группа «Свободные задачи». При «Взять» считаются задачи участника, которые он взял сам (событие `assigned` с автором-исполнителем) и которые ещё не приняты и не отменены (`assigned`, `in_progress`, `in_review`, `needs_work`). Достигнут предел: 409 `OPEN_TASK_LIMIT` с текстом для участника. Две одновременные попытки одного участника сериализуются `pg_advisory_xact_lock`. Предел действует сразу, миграции не нужно.
- **Уведомление создателю** (владелец: «Уведомления делай»). Миграция 000044 добавляет вид `task.claimed` (привязан к задаче, уникален на задачу). При «Взять» создателю ставится сообщение «В приложении участник взял вашу свободную задачу.» (фиксированный текст, без названий). Если создатель взял свою задачу сам, сообщения нет. Доставка идёт той же очередью и worker; получатель должен был нажать Start у бота, как для остальных видов.

## Эксплуатация

Текст сообщения берётся из `neutralNotification`, который собран в worker. Пока Edge Functions не пересобраны (`bun run build:edge`) и не выкачены заново, worker подавит `task.claimed` как неподдерживаемый вид (`unsupported_kind`), приложение при этом работает. Порядок выкладки: миграция 000044, затем функции, затем включение.
