# ADR-0022: неизменяемая отмена будущих условий

Дата: 06.10.2026. Статус: технический контракт синтетического режима; P-решения не согласует.

Будущая публикация должна иметь проверяемую отмену до вступления в силу. `catalog_cancellations` сохраняет отдельное неизменяемое свидетельство вместо UPDATE/DELETE условий. Effective readers исключают отменённые версии; история и audit сохраняют обе операции. Операция использует прежний identity/quota barrier, отдельное exact право, default-false flag и idempotency namespace. Сервер и DB проверяют время после ожиданий.

Новый номер — max всех сохранённых версий + 1, previousVersion указывает действующие условия; guard публикации и response допускают пропуски отменённых номеров. Миграция 000030, API и UI выпускаются совместно. Выключение flag останавливает новые отмены, но не отменяет сохранённые свидетельства. Down запрещён ради истории. Runtime, транспорт, зависимости и границы модулей сохраняются.

Проверки: PostgreSQL locks/races/ACL/immutable evidence, независимые ожидаемые ресурсы и выбранные версии, HTTP/UI и restore. Это не real policy, performance claim или завершение R1.
