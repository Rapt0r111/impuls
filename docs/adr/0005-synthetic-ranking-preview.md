# ADR-0005: ограниченный синтетический рейтинг до P-05

Дата: 02.10.2026. Статус: инженерная граница локального режима ожидания; не решение владельца P-05.

План требует F05 и одновременно выключенной публикации реального рейтинга до P-05. Общий allowlist и полномочия управления задачами не определяют право видеть имена/результаты других участников.

Выбран read-only preview под отдельным выключенным по умолчанию SYNTHETIC_RANKING_ENABLED. Только действующее явно синтетическое членство в точной области позволяет читать псевдонимы и положительные суммы XP этого синтетического состава. Общий рейтинг роты, наследование admin/task.view, реальные имена, нулевой публичный список и межобластные суммы не вводятся. Клиент не управляет членством или видимостью. Это техническая политика синтетического теста, которую нельзя переносить на реальный пилот без P-05.

Существующий журнал содержит исходный сезон компенсации; рейтинг суммирует его со знаком. Сезон выбирается в Europe/Moscow. Опубликованных снимков пока нет: прошлый месяц явно остаётся текущим расчётом журнала, не архивом/кубком. Неизменность будущих снимков и errata требуют следующего контракта.

Для масштаба около 40 человек полный доступный итог области используется как revision для курсора. При изменении состава, имени или XP очередная страница возвращает 409. Это исключает смешивание разных расчётов, не создавая ложного «снимка сезона». Постоянное хранение снимков, индексы и измерения добавляются при соответствующем срезе/нагрузке.

Проверки: границы месяца, 1/2/2/4 и UUID, изоляция области/валюты/зоны, компенсация исходного месяца, членство/отзыв/сессия, пагинация/409, отсутствие операций записи, UI на мобильных размерах. Архитектура Next.js→domain→PostgreSQL и существующие RLS/гранты сохранены. Откат приложения — выключение флага; схема не изменена.
